# Ambre Pro — versions

Versions compilées d'**Ambre Pro**, le module exclusif d'[Ambre](https://github.com/victorlej/ambre) (le moteur d'Allia) :

- **compteur Ambre** : dans DXVK, et dessiné dans l'image avec Ambre Metal ;
- **mesure des performances** pour Allia (temps de chaque image, 1 % et 0,1 % bas, stabilité) ;
- **génération d'images** pour Ambre Metal (macOS 26 et plus) : une image fabriquée entre deux vraies, affichées au rythme de l'écran ;
- **cache des shaders**.

Ce dépôt ne contient **que des fichiers compilés** (onglet *Releases*), téléchargés et vérifiés par Allia
(empreinte SHA-256 dans les notes de chaque version). Le code d'Ambre Pro est privé.

Ambre Pro s'appuie sur [DXVK-macOS](https://github.com/Gcenx/DXVK-macOS) (licence zlib, © Philip Rebohle et
contributeurs, © Gcenx) et se branche sur les prises génériques d'Ambre Metal. Les modifications de Wine et de
[DXMT](https://github.com/3Shain/dxmt) faites pour Allia sont publiques, dans le dépôt
[ambre](https://github.com/victorlej/ambre).
