# Ambre Pro — versions

Versions compilées d'**Ambre Pro**, le module exclusif d'[Ambre](https://github.com/victorlej/ambre) (le moteur d'Allia) :
compteur d'images Ambre, mesure des performances pour Allia, cache des shaders.

Ce dépôt ne contient **que des fichiers compilés** (onglet *Releases*), téléchargés et vérifiés par Allia
(empreinte SHA-256 dans les notes de chaque version). Le code d'Ambre Pro est privé.

Ambre Pro s'appuie sur [DXVK-macOS](https://github.com/Gcenx/DXVK-macOS) (licence zlib, © Philip Rebohle et
contributeurs, © Gcenx). Les modifications de Wine faites pour Allia sont publiques, dans le dépôt
[ambre](https://github.com/victorlej/ambre).
